构造RTDE控制接口会上传控制脚本；本程序只有在用户RUN/RECOVER确认后才进入这一流程。`--check`只读查询，不构造控制接口。`--preview`为纯离线计划。

控制脚本设置1 Hz看门狗；轮询反馈时喂狗。程序核对状态新鲜度、运行状态、实际速度/姿态、单个目标控制器限位及到位。代码中的stopL是软件停止请求，不代表安全级急停。未通过Dashboard发送上电、松闸、解锁保护停止或清报警动作。

## 帧与寄存器

地址均为零基协议地址，无40001偏移。CRC16初值0xFFFF、多项式0xA001，低字节先发送。读状态使用功能码03；运动使用功能码10连续写0x1600开始的6个字：

| 地址 | 字段 | 定位命令值 |
|---|---|---|
| 0x1600 | 目标位置，0.01 mm | 0 / 1300 / 4800 |
| 0x1601 | 推压距离 | 0 |
| 0x1602 | 速度，0.01 mm/s | 100 |
| 0x1603 | 加减速度百分比 | 1 |
| 0x1604 | 推力百分比 | 0 |
| 0x1605 | 控制字 | 先0x20再0x21，产生定位上升沿 |

写入需要校验应答CRC、地址与字数，不自动重发失败的运动命令。软件暂停用功能码06写0x1605=0x28，保持使能，不强制松抱闸。中断恢复使用完整的全新目标0 mm指令，避免仅清暂停后重放旧目标。

| 地址 | 状态字段 |
|---|---|
| 0x0200 | 回零状态：0未回零、1完成、2回零中 |
| 0x0302 | 站号 |
| 0x0306 | 行程限制，0.01 mm |
| 0x0308 | 原点偏置，0.01 mm |
| 0x0402 | I/O控制模式 |
| 0x160C | 实际位置，0.01 mm |
| 0x160F | 报警码 |
| 0x1611 | 扩展状态字 |

0x1611状态位：bit10使能、bit9报警、bit8运动中、bit6已回零、bit5到位。到位位不等同于已回零。位置容差为5原始值即0.05 mm。程序在位置及运动/到位反馈连续稳定后确认完成。

只读程序保留55项公开地址读取能力；完整寄存器对照见[电缸协议原始研究记录](电缸协议原始研究记录.md)。本机不能由寄存器读回独立证明铭牌序列号或完整工厂配置。
