# 问题与修复记录

| 现象 | 本次证据/原因 | 已采用处理 |
|---|---|---|
| ModuleNotFoundError: No module named serial | VS Code使用的Python解释器缺少pyserial | 在同一Python解释器中安装pyserial3.5；依赖文件固定版本；模块名称为serial，安装包为pyserial |
| 起始Rx/Ry/Rz不为0被阻止 | 早期版本要求零姿态 | 曾加入单独初始化；最终用户改为固定实测姿态，常规零姿态初始化已删除 |
| Existing robot program is running or paused | 控制器报告另一个程序正在运行或暂停 | 先在现场处理既有程序，生成程序不覆盖；该检查仍保留 |
| 输入RUN后无动作、Stopped: KeyboardInterrupt | 日志显示键盘/调试器中断，部分发生于预采样或等待 | 记录失败阶段；去除全路径预采样；最终去除全部逐段GO等待 |
| Initialization angular speed exceeded 0.02 rad/s | 早期自定义角速度瞬时监控阈值触发 | 删除该额外监控阈值；速度只记录 |
| Robot speed exceeded trial monitoring threshold | 早期自定义速度监控触发 | 删除额外瞬时平移速度中断；保留实际命令速度和其他到位/状态核验 |
| 人工停止后，控制字包含暂停且电缸不在0 | 本次0x28暂停、位置48 mm，已回零且无报警 | 加入RECOVER；下发全新目标0 mm完整参数0x20→0x21，回0后再执行下一恢复项 |
| Current orientation differs from captured fixed orientation | 人工干预后姿态偏离原快照 | RECOVER在当前XYZ恢复原固定姿态；不自动捕获新值，不改为零姿态 |
| COM4不存在 | 最近14:44本地启动日志提示端口找不到；用户说明设备已断开 | 保留日志与提示；离线计划/测试不连接设备；重新接入后核对实际串口 |
| 早期COM3 WriteFile failed/PermissionError | 既有独立电缸方向测试项目末段15→25 mm未完成，随后COM3消失 | 历史测试不记录为已返回25 mm；断线前15 mm不当作实时位置；重连先读状态，不补发动作 |

Python环境示例：

```powershell
python -m pip install -r requirements.txt
python -c "import sys, serial; print(sys.executable); print(serial.__version__)"
```

VS Code选择的解释器应与安装依赖的解释器一致。当前单文件导入时仍需pyserial依赖，离线几何模拟simulate_ag.py仅使用标准库。

最终版没有 `--step` 参数或逐段GO输入；正常RUN与恢复RECOVER各仅确认一次。中断后程序不会自动续跑，不自动解除硬件急停、保护停止或报警。
